如何自定义你的导航页

1

添加新分类

在 id="categoryBar" 的 nav 标签内添加新的分类按钮：

<button class="cat-btn bg-ink-100 dark:bg-ink-800 
  text-ink-500 px-4 py-1.5 rounded-full text-sm"
  data-cat="新分类ID">
  分类名称
</button>

然后添加对应的 <section data-category="新分类ID"> 区域。

2

添加新链接卡片

在对应分类的 grid 容器内添加：

<a href="链接URL" target="_blank"
  class="nav-card fade-up block bg-white 
  dark:bg-ink-800 rounded-2xl p-5 border..."
  data-name="资源名称"
  data-keywords="搜索关键词">
  <!-- 图标 -->
  <h3>标题</h3>
  <p>描述</p>
</a>

data-name 和 data-keywords 用于搜索功能。

3

修改主题配色

在 tailwind.config 中修改 accent 色板：

accent: {
  50:  '#eefcf5',  // 最浅
  400: '#3fc994',  // 主色
  500: '#1bb077',  // 强调
  700: '#0f704c',  // 深色
  900: '#0a4530',  // 最深
}

替换为你喜欢的颜色色板即可。

4

部署上线

将 HTML 文件部署到免费托管平台：

  • GitHub Pages：推送到仓库后在 Settings 中开启 Pages
  • Vercel：导入仓库后自动部署，秒级上线
  • Netlify：拖拽 HTML 文件即可发布
  • 本地使用：直接双击 HTML 文件用浏览器打开
