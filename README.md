# 男士裤装类目指引与优化集合页

> 男士裤装电商运营一站式导航页面，整合类目指引、开款方向、视觉优化与标题优化四大板块。

## 📁 项目结构

```
.
├── navigation_index.html   # 导航集合页主文件
├── README.md               # 项目说明文档
├── .gitignore              # Git忽略配置
├── screen_1.png            # 类目指引图
├── img_open_direction.png  # 开款方向图
├── img_visual_main.png     # 主图优化参考图
├── img_visual_detail.png   # 细节图优化参考图
├── img_title_hot.png       # 站内爆款热搜词
├── img_title_shein.png     # SHEIN BSR热搜词
└── img_title_category.png  # 分类目热搜词
```

## 📋 板块说明

| 序号 | 板块 | 内容 | 包含资源 |
|------|------|------|----------|
| 1 | 类目指引 | 10个裤型上款路径 | 类目指引图 + 路径详情 |
| 2 | 开款方向 | 开款方向问卷链接 | 类目规划与企划方向图 |
| 3 | 视觉优化 | 主图优化 + 细节图优化 | 场景拍摄参考图 + 面料细节参考图 |
| 4 | 标题优化 | 站内爆款 / SHEIN BSR / 分类目热搜词 | 3张关键词数据图 |

## 🚀 使用方式

1. 直接在浏览器中打开 `navigation_index.html` 即可访问集合页
2. 点击各板块内的链接跳转至对应问卷
3. 图片资源需与HTML文件放在同一目录下

## 📌 类目覆盖

- 休闲裤、工装裤、户外/战术裤
- 运动裤、廓形休闲裤、跑步长裤
- 高尔夫裤、马术裤、新奇版型、骑行裤

## 🎨 技术栈

- 纯 HTML + CSS（无外部依赖）
- 响应式布局，支持移动端
- 渐变色卡片设计风格
